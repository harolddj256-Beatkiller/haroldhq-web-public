Which product is right for me?

Harold DJ Pro is the DJ performance workspace. Radio Studio brings station planning and playout together. Beklo focuses on the rider journey. Each product page shows its interface and main workflows.

Where can I download the software?

Public download links are not available on this site yet. The release section on each product page will show official downloads and supported platforms when they are confirmed.

Are these the current software interfaces?

Yes. The interface galleries were captured from DJ Pro 4.3.41, Radio Studio Network Pilot network.3, and Beklo 2.1.0. Preview data is used for the captures. The photographic scenes use those screens in real photographs.

Can I book a ride through this website?

This is Beklo’s product showcase. Booking, service areas and public app availability will be announced as part of Beklo’s launch.
